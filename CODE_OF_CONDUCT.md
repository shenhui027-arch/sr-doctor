# 行为准则 / Code of Conduct

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 作为行为准则。参与 Issue、PR 与讨论时，请以友善、尊重、对事不对人的方式交流。

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Please be kind, respectful and constructive in issues, pull requests and discussions.

如需报告违反行为准则的情况，请按 [SECURITY.md](SECURITY.md) 中的私密渠道联系维护者，不要在公开 Issue 中讨论。
To report unacceptable behaviour, contact the maintainer through the private channel described in [SECURITY.md](SECURITY.md) rather than in a public issue.
